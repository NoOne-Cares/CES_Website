## Setup and Installation

To get started with the project, follow these steps:

1. **Clone the Repository**

   ```bash
   git clone https://github.com/NoOne-Cares/CES_Website.git
   cd CES_Website
   ```

2. **Install Dependencies**

   
    Install the project dependencies using PNPM:
    ```bash
    pnpm install
    ```

3. **Start the Development Server**
    
    Start the Vite development server:
    ```bash
    pnpm dev
    ```

## Development

To contribute to the development of the website:

1. **Create a New Branch**

    ```bash
    git checkout -b <branch-name>
    ```

2. **Make Your Changes**

    Edit files as needed to implement new features or fix issues.

3. **Test Your Changes**

    Run the development server to ensure your changes work as expected:

    ```bash
      pnpm dev
    ```
4. **Commit Your Changes**

    Stage and commit your changes:

  ```bash
    git add .
    git commit -m "Describe your changes"
  ```
5. **Push Your Branch**

    Push your branch to the remote repository:

  ```bash
    git push origin <branch-name>
  ```
6. **Create a Pull Request**

    Open a pull request from your branch to main (or the appropriate base branch) on GitHub.

## Linting and Formatting
To maintain code quality and consistency:

- Run ESLint

  ```bash
  pnpm lint
  ```

- Auto-Fix Linting Issues

  ```bash
  pnpm lint:fix
  ```

- Format Code

    ```bash
    pnpm format
    ```
